La curva de aprendizaje de Ext JS es algo grande y requiere tiempo de práctica además de investigación y mucho tiempo de lectura y entrenamiento; es por este motivo que nació Quizzpot, para ayudarte a reducir el tiempo de aprendizaje de esta herramienta.

Hasta ahora hemos publicado varios tutoriales que seguramente te han ayudado en tu aprendizaje, como parte de nuestra ayuda queremos darte además servicios de entrenamiento personalizado, de esta manera lograrás desarrollar tus proyectos en menor tiempo y con buenas prácticas, hemos creado algunos paquetes para que elijas el que más te convenga.

Paquetes

  • Paquete 1: Ext JS + Java Servlets + MySQL

    El objetivo de este taller es mostrar la integración de Ext JS con los Java Servlets, además se utiliza MySQL como servidor de Base de datos.

  • Paquete 2: Ext JS + Java Spring Framework + Hibernate + MySQL

    Este taller está pensado para empresas/personas que estén familiarizados con estas herramientas ya que no se ve a detalle el uso de Spring y Hibernate, el objetivo principal es mostrar la integración de Ext JS con estos Frameworks, lo sencillo y rápido que es hacerlos funcionar en conjunto.

  • Paquete 3: Ext JS + PHP + MySQL

    PHP es un lenguaje muy utilizado en Internet, este taller está pensado para las personas/empresas que trabajan con PHP, la idea es mostrar una manera sencilla de poder integrar estas herramientas.

  • Paquete 4: Ext JS + Code Igniter + MySQL

    Code igniter es uno de los mejores Frameworks existentes para PHP, su excelente arquitectura nos permite desarrollar nuestros proyectos con mayor rapidez, en este taller se muestra como integrar este Framework con Ext JS.

En todos los paquetes cubrimos los componentes GUI del Framework, además mostramos como desarrollar tus propias extensiones y lo más importante como desarrollar una aplicación de gran tamaño y hacer que los componentes se comuniquen entre si. En el taller desarrollaremos una aplicación que utilice los componentes más solicitados, de esta manera podrás comenzar a ser productivo rápidamente con Ext JS.

Duración

La duración de los talleres es de 8 sesiones y la duración de cada sesión es de 2 horas, tú decides el horario de las sesiones solo contáctate con nosotros para agendar los talleres.

Lugar

El lugar puede ser las instalaciones de tu empresa o si lo deseas puede ser realizado a través de Internet.

Inversión

El costo de los cursos es de $350.00 Dlls + IVA por persona pero puede variar dependiendo del grupo de personas a tomar el curso, aplicamos descuentos a equipos grandes, si tu empresa se encuentra fuera de Monterrey Mx y deseas que los talleres sean realizados en tus instalaciones hablaremos acerca de los viáticos.
