Tags: CSS3 Bootstrap

Sin lugar a dudas Bootstrap es el framework más popular de CSS, y no es para menos ya que nos permite crear sitios usando Responsive Design y Mobile First de una manera rápida.

A continuación muestro los mejores sitios donde conseguir templates gratuitos y de muy buena calidad, todos hechos con bootstrap.

Bootstrap Cero

Bootstrap cero cuenta con cientos de templates de muy buena calidad, podrás encontrar templates iniciados, es decir layouts comunes para que a partir de ahí tu mismo agregues los estilos que desees. También hay una colección de templates terminados, listos para usarse, sin duda aquí encontrarás el template necesario para tu proyecto, desde administradores, portafolios, landing pages y páginas personales.

Bootstrap Cero


Start Bootstrap

Una librería de temas hechos en Bootstrap 3, muy buenos diseños y lo mejor de todo es que son Open Source, eso significa que los podemos utilizar mediante la licencia Apache License, Version 2.0.

Temas Open Source en Bootstrap 3

Get Template

En este sitio hay pocos templates, pero muy bien hechos, ademas cuenta con un template builder para que puedas hacer tu template de manera rápida y sencilla, sin lugar a dudas uno de mis sitios favoritos.

Prep Bootstrap

En este sitio hay algunos templates interesantes, así como layouts inicializadas para comenzar a desarrollar nuestro propio tema.
