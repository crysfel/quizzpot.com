Descripción del tema

En este tema veremos como crear un repositorio en GIT para poder comenzar a versionar nuestro proyecto.

Supongamos que vamos a iniciar a trabajar en un proyecto con rails y usaremos GIT como nuestro sistema de versionamiento.

Para este curso usaremos rails como ejemplo, ya que nos genera varios archivos de manera automática. Pero para realizar los ejemplos puedes usar cualquier otro framework o inclusive crear una carpeta e ir añadiendo archivos. 

Iniciaremos creando nuestro proyecto ejecutando el siguiente comando para generar nuestra aplicación rails. 

$ rails new myapp
$ cd myapp

Crear un repositorio en GIT es bastante sencillo, basta con ejecutar el siguiente comando dentro del directorio raíz en nuestro proyecto.

$ git init

Al ejecutar el comando anterior se creará un directorio oculto llamado .git en el folder raíz de nuestro proyecto. Este folder contiene toda la información necesaria para que GIT pueda llevar un historial del avance de nuestro proyecto.

GIT funciona de manera local, es decir que a diferencia de otros sistemas de versionamiento (como CVS o SVN), no necesitamos tener un servidor central donde estemos sincronizando nuestros cambios. Todo funciona de manera local, eso hace que GIT sea bastante rápido al realizar ciertas operaciones donde SNV o CVS son bastante lentos.

Ya que GIT funciona de manera local es una estupenda opción para proyectos donde no es necesario trabajar con un equipo de personas, donde simplemente queremos llevar un control de nuestros avances y usar todo el potencial de GIT. Aunque cuando trabajamos en equipo es cuando GIT realmente sobresale.

Si bien es cierto que GIT funciona de manera local, no significa que no podamos sincronizar nuestros cambios con algún otro servidor remoto. Mas adelante en este curso veremos como podemos agregar uno o más repositorios remotos y sincronizar nuestros cambios, esto es perfecto para cuando trabajamos en equipos distribuidos.
