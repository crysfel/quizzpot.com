Descripción del tema

Para poder desarrollar aplicaciones con Sencha Touch deberíamos instalar algunas herramientas adicionales que nos ayudarán a desarrollar de una manera más sencilla. 

Primero necesitamos tener instalada alguna versión de Java, mi recomendación es instalar Java 7 para poder compilar nuestro CSS más rápido, pero Java 6 nos funcionara bien. Java es utilizado por el Sencha CMD internamente, así que es necesario tener instalado Java para no tener ningún problema.

En segundo lugar necesitamos tener instalado Ruby, te recomiendo utilizar el RVM para instalarlo, puedes instalar la versión 1.9.3 pero mi recomendación es instalar la versión 2.1. Ruby lo utiliza internamente el Sencha CMD para compilar los archivos SASS a CSS, de esta manera podrémos cambiar el Look and Feel de la aplicación muy fácil.

Por último es necesario instalar el Sencha CDM, con esta herramienta vamos a generar la aplicación inicial, vamos a comprimir y ofuscar nuestro código para que se cargue más rápido en el dispositivo, también nos puede servir para deployar nuestra aplicación usando PhoneGap al dispositivo de nuestra preferencia.

Adicionalmente vamos a utilizar GIT para llevar el control de nuestro código, utilizaremos GitHub, puedes revisar el curso que tenemos de GIT en caso de que no conozcas como funciona este sistema de versiones.

En este punto puedes descargar la librería de Sencha Touch, desde la página oficial de Sencha, para este proyecto utilizaremos la versión 2.3.1. En el siguiente tema vamos a utilizar esta librería para generar nuestro proyecto.
